# Экспериментальная сортировка MAX

На карточке с текстом есть две отдельные стрелки: `→ MiniLM` и `→ TF-IDF`. Каждая запускает только выбранную модель. Результаты хранятся рядом и не затирают друг друга. Во время задания обе кнопки блокируются; при ошибке их можно нажать снова. Пост остаётся в «Не готовы», пока хотя бы одна классификация не завершилась успешно. Внутри «Отсортирован» можно запустить вторую модель и сравнить ответы.

Пост без текста сортируется сразу при импорте, без worker и кнопок. С медиа он получает категорию **«Только медиа»**; без медиа — **«Пустое сообщение»**. Оба случая отделены от смысловой классификации. `python -m app.taxonomy.backfill` один раз переводит ранее скачанные пустые посты в эти статусы; повторный запуск не дублирует строки.

Разметку 3000 обучающих текстов сделал Codex. TF-IDF baseline и MiniLM обучались на ней независимо. На отложенных метках Codex macro-F1 составил 0,518 и 0,234 соответственно; это согласие с разметкой агента, а не независимая точность. MiniLM оставлена для ручного сравнения по прямому запросу владельца. Проценты в интерфейсе — **некалиброванные оценки**, не вероятность истины. Они не управляют автоматической публикацией.

`POST /api/pipeline/{entry_id}/taxonomy/{tfidf|minilm}` под существующей Basic Auth ставит задание. Таблица `taxonomy_classifications` хранит отдельную строку по `(pipeline_entry_id, model_key)`. `0009` переводит старые результаты в ключ `tfidf`, старые пустые — в ключ `media`. Текст остаётся только в `telegram_posts`; таблица заданий хранит его SHA-256, модель, оценки и время. При правке текста старые оценки становятся устаревшими.

TF-IDF worker читает `baseline.joblib`, отдельный MiniLM worker — `minilm-v1/epoch-2.safetensors`, локальный tokenizer и config. Оба читают общую `taxonomy.json`. Веса и тексты корпуса лежат вне Git. MiniLM-образ содержит PyTorch; веб и TF-IDF-образ его не загружают. MiniLM ограничена 2 GiB RAM и одним CPU, TF-IDF — 768 MiB и одним CPU. Никакой worker не использует внешние API при inference.

На production нужны защищённые `TAXONOMY_ENABLED=true`, `TAXONOMY_MODEL_DIR`, `PUBLISHER_IMAGE` и `PUBLISHER_MINILM_IMAGE`, миграция `alembic upgrade head`, закреплённые образы и оба worker. Compose подключает каталог весов только для чтения. Collector, внешние LLM, рерайт и публикация не включаются этим релизом.
